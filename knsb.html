How to read these numbers

Average rating is weighted by appearances, using each encounter’s published ratings. Opponent rating uses those same appearances on the other side. “Above expected” adds up actual minus expected board points using 1 / (1 + 10^((opponent rating − player rating) / 400)). This is a simple rating baseline, not a measure of luck or a match prediction.

Only scored games with two named players and valid ratings enter that baseline. Walkovers, missing ratings and unrecognised result formats are excluded. With only a few rounds, the sample is small. Last lineups are historical, not confirmed future selections. Position history uses match points then board points, with equal positions for ties; official extra tie-breaks may differ.

Dates are published round dates; individual encounters can move. Times and venues are not included in this first version. Updates run twice daily; corrections replace the current data and the previous version is archived.
